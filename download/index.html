What is not in this release

  • No macOS binary. The apps build and run on macOS, but 1.3.2 was packaged for Windows only, as every release since 1.2.7 has been.
  • No iOS binary. The iOS targets are in the source tree and syntax-checked, but nothing is packaged for the App Store in this release.
  • The Windows installers are unsigned. SmartScreen will show “Windows protected your PC”; choose More info, then Run anyway. The Android APK is signed with the same release key as every prior build.

System requirements.

Windows
Windows 10 or later, x64 or arm64. Roughly 500 MB free after install.
macOS
macOS 12 or later. Build from source until a packaged release ships.
Android
Android 7.0 (API 24) or later. Built against API 34.
iOS
POS companion: iOS 17 or later. Owner App: iOS 26 or later.
Browser
Any current Chrome, Edge, Firefox or Safari. IndexedDB must be available — it is where the offline replica and the outbox live.
Printer
Any ESC/POS thermal printer. Network printers over raw TCP on port 9100; USB and Bluetooth printers through the printer the operating system already has installed.
Server
The ERP, the reports and the assistant need a connection to your ForkStack server. The till does not.

Install notes.

Pairing a terminal

A fresh install asks for an admin sign-in once, then binds the device to a single outlet — by QR from a manager's phone, or by picking the outlet after that admin login. Printers, tables, menu and tenders all follow from the pairing. Floor staff never see an email field again; they sign in with a name and a 4-digit PIN.

Setting up a printer

In Manager → Setup → Printers, add a network printer by IP and port (9100 is the default) or pick one the machine already has installed. Assign categories to printers for KOT routing, and choose how tickets are split on a shared printer: one per printer, one per station, or one per category.

First run

The setup wizard creates the organization, the first outlet and the admin account, and takes the currency symbol, tax rate and whether prices are tax-inclusive. Get those right at the start — they shape every bill the outlet will ever print.
